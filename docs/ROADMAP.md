# Goodscroll release roadmap

## V1.0 — Starter (this archive)
Functional static app, curated seed feed, three live-source adapters (untested remotely), mood controls, saves, quizzes, health JSON.

## V1.1 — Content quality
Source adapter integration tests, stronger rights verification, accurate source-specific licensing and credits, content freshness, duplicate detection across sources, human review queue, better category diversity.

## V1.2 — Rich media
Openverse adapter, reliable YouTube embed support with permission-aware playback, proper image fallbacks, media load monitoring, responsive galleries, creator spotlights.

## V1.3 — Curiosity engine
Related discoveries, topic trails, topic subscriptions, explicit serendipity controls, smarter on-device ranking, user-readable recommendation explanation.

## V1.4 — Interactive library
Ten distinct interactive card formats, progress kept locally, accessible keyboard/touch controls, offline-ready game bundles.

## V2 — Trust and optional sync
Consent-based user accounts and sync, moderation pipeline for submissions, transparent feedback analytics, comprehensive accessibility audit.
